# BMI Calculator

## 1. Project Overview

The BMI Calculator is a desktop application developed using Python
and Tkinter. It calculates Body Mass Index (BMI) using the user's
height and weight and displays the corresponding BMI category.

## 2. Objectives

- Develop a simple graphical application using Python.
- Apply functions, conditional statements, and exception handling.
- Calculate BMI using a mathematical formula.
- Validate user input and handle errors.
- Practise software development and version control using GitHub.

## 3. Technologies Used

- Python
- Tkinter
- VS Code
- Git
- GitHub

## 4. BMI Formula

BMI = Weight (kg) / Height (m)^2

Height is entered in centimetres and converted into metres
before the calculation.

## 5. Features

- Height and weight input fields.
- Automatic BMI calculation.
- BMI category display.
- Input validation.
- Error messages for invalid inputs.
- Clear button to reset the form.

## 6. BMI Categories for Adults

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 to below 25 | Healthy weight |
| 25 to below 30 | Overweight |
| 30 and above | Obesity |

BMI is a screening tool and is not a medical diagnosis.

## 7. How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run:

   python bmi_calculator.py

Tkinter is included with most standard Windows Python installations.

## 8. Testing

Test the application with valid height and weight values, empty
fields, non-numeric input, zero, and negative values.

## 9. Conclusion

This project demonstrates the use of Python functions,
conditional statements, exception handling, and GUI development
